# Content Sample — MDLIVE Virtual Care

A reference library of approved copy samples organized by service line. Use these as style principles for content and marketing voice, tone, and messaging when writing new copy for virtual healthcare services.

## Voice & Tone Principles

These principles are derived from the approved copy below. Follow them when writing new content:

- **Warm and professional** — empathetic but not clinical. Write like a trusted healthcare partner, not a medical textbook.
- **Action-oriented** — lead with what the patient can do, not what the system does. "See a doctor in minutes" not "Our platform enables virtual consultations."
- **Specific over generic** — use concrete details (time estimates, step counts, provider counts) instead of vague promises. "Under 2 minutes" not "quickly." "4.8-star rating" not "highly rated."
- **Parallel structure** — all cards in a set follow the same grammatical pattern. If one heading starts with a noun, all should.
- **Plain language** — no jargon. "See a doctor" not "access a telehealth consultation."
- **Link labels are specific verbs** — "Get Care Now", "Find a Therapist", "Search Providers" — never generic "Learn More" or "Click Here."
- **Credibility through numbers** — weave in stats naturally: "2M+ visits", "4.8★ rating", "<10 min wait", "30 min visits."
- **Empathy in CTAs** — closing CTAs acknowledge the patient's situation: "Don't wait when you're not feeling well" or "You don't have to do this alone."

## Messaging Patterns

### Hero Headlines
- Benefit-first, 4–8 words
- Examples: "Quality Care in Minutes, Not Hours" / "Urgent Care — Anytime, Anywhere" / "Mental Health Support, on Your Terms" / "Primary Care, From Your Living Room" / "Dermatology — Fast, Customized Care"

### Hero Body Copy
- 1–2 sentences. Establishes credibility + eliminates friction.
- Pattern: [What you get] + [how easy it is] + [no friction]
- Example: "Join over 2 million patients who trust MDLIVE for virtual urgent care, therapy, dermatology, and primary care. Sign up in under 2 minutes — no downloads, no hassle."

### Section Headings
- Eyebrow (1–3 words, category) + Heading (4–8 words, benefit-driven)
- Examples: "Virtual Care" + "One Platform, Every Specialty You Need" / "How It Works" + "Virtual Care Set Up in Minutes"

### Card Copy
- Title: 2–5 words, specific service or feature name
- Description: 1–2 sentences, lead with what the patient gets
- Link: specific action verb, 2–4 words

### Metric Highlights
- Number + unit/symbol: "2M+", "4.8★", "<10 min", "30 min", "95%", "Same-Day", "90%", "$0–95"
- Label: 3–8 words explaining the metric

### CTA Banners
- Heading: bold, empathetic statement or brand tagline
- Subtext: 1 sentence, direct call to action
- Primary button: main action / Secondary button: explore path

## How to Use This Reference

1. **When writing new copy for an existing service line** — find the matching section above and follow the same voice, structure, and specificity level. Adapt the content but keep the tone.
2. **When extending to a new service line** — use the patterns above as templates. Match the hero headline structure, card copy depth, CTA empathy level, and metric format.
3. **When populating component variants** — match the component type to the relevant section (e.g., highlight brand → Benefits pattern, highlight metric → Metrics pattern, promo-banner → Promo pattern).
4. **When writing CTAs** — closing CTAs should acknowledge the patient's emotional state or situation, not just describe an action.
5. **When choosing link labels** — always use specific action verbs. Each link label should tell the user exactly where they're going.
